# Artificial Intelligence Observability

## About
This repo is my experimentation playground for building and observing agentic artificial intelligence systems. 

I'm not sure where I'm going with this repo yet. But I'm experimenting with multi-agent architectures, including orchestrators, specialized subagents, tool calling, retrieval-augmented generation (RAG), and other emerging agentic patterns. A major goal of this project is to experiment with OpenTelemetry to trace and observe agentic AI workflows.

The backend is implemented as a Golang REST API service and is intended to serve as the orchestration layer for AI workflows, external tools, model providers, and telemetry. OpenTelemetry will be used to capture traces, metrics, and execution flow across requests, LLM calls, tool usage, agent handoffs, and other important operations.

Areas of experimentation include:

- Agent orchestration and subagent architectures
- Tool calling and external API integration
- Retrieval-augmented generation (RAG)
- LLM tracing and OpenTelemetry instrumentation
- Model and agent evaluation
- Prompt and workflow experimentation
- Latency, token usage, cost, and error monitoring
- Observability of agent decisions and tool calls
- Structured outputs and API contracts
- Concurrent and asynchronous agent workflows
- Interactive frontend experiences driven by AI
- ReAct agents
- jev

## Terminal Installations

- Gin REST API framework  
    - `go get "github.com/gin-gonic/gin"`
- Load environment variables from .env  
    - `go get "github.com/joho/godotenv"`
- Swagger/OpenAPI UI for Gin
    - `go get "github.com/swaggo/gin-swagger"`
    - `go get "github.com/swaggo/files"`
- Swagger/OpenAPI generator
    - `go get "github.com/swaggo/swag"`
    - `go install github.com/swaggo/swag/cmd/swag@latest`


## Regenerate Swagger Documentation

- Run this from the backend/ directory after changing Swagger annotations.
    - `swag init -g ./cmd/api/main.go --parseInternal --parseDependency`
